2. Reconstruct speed, target speed, lead gap, TTC, longitudinal acceleration, jerk and emergency intervention.
3. Compare expected versus observed behavior and identify first divergence.
4. Reproduce using deterministic scenario fixtures; capture seed and build.
5. Record suspected subsystem, confidence, counterevidence and unknowns.
